# Relationship Spice — Releases

This repository hosts **only the compiled Android APK releases** and their
changelogs for the Relationship Spice app. It contains no source code and
no app content.

The app itself is developed in a private repository. This repo exists so
the app's in-app "Update" check can query GitHub's public Releases API
without needing a private-repo access token embedded in the APK.

Each release's notes describe what changed in that version.
